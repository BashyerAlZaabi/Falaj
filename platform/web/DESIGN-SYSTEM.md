# Liquid Glass design system — Smart Work Platform

Apple‑inspired, restrained, Arabic‑first (RTL) with full English/LTR, light and dark designed separately.
Glass is used **selectively** to express depth — never "everything transparent".

## Files
| File | Purpose |
|---|---|
| `css/tokens.css` | **All** design tokens (color, glass levels, type, spacing, radius, shadow, motion, z‑index) + accessibility fallbacks |
| `css/base.css` | Fonts, reset, ambient background, type scale classes (`.t-*`), utilities, keyframes, reduced motion |
| `css/components.css` | Component library (surfaces, buttons, fields, switches, segmented tabs, chips, cards, lists, tables, progress, tooltip, popover/menu, modal/sheet, toast, skeleton, empty state, command palette, callouts) |
| `css/shell.css` | App shell: sidebar, floating toolbar, workspace, inspectors (Ask AI, document), login, mobile tab bar/drawer |
| `css/pages/*.css` | Page‑specific layout only (dashboard, adaa, work, documents, chat, office, admin) |
| `js/ui.js` | JS primitives: `h`, `icon`, `toast`, `modal`, `confirmDialog`, `menu`, `segmented`, `skeleton`, `emptyState`, `errorState`, `dataTable`, `field`, `md` |
| `js/icons-data.js` | Lucide icons (generated by `scripts/build-icons.mjs` — add names there, never hand‑edit) |

**Rule:** components and pages consume tokens (`var(--…)`). No hex colors, ad‑hoc radii, shadows or durations in page CSS or inline JS styles. Inline `style` in JS only for truly dynamic values (e.g. a progress width).

## Depth & glass levels
| Level | Class | Use | Blur |
|---|---|---|---|
| 0 | `.ambient` | Page environment (soft color fields) | — |
| 1 | `.glass-1` | Large ambient workspace surfaces | yes |
| 2 | `.glass-2`, `.card` | Content cards, grouped lists, table containers | **no** (sits inside blurred parents → avoids stacked blur) |
| 3 | `.glass-3` | Floating chrome: sidebar, toolbar, inspectors, tab bar | yes |
| 4 | `.glass-4` | Modals, sheets, popovers, command palette, toasts | stronger |
| 5 | `.glass-5` | Focused / active interactive surface (selected nav item, active segment) | — |

Fallbacks: no `backdrop-filter` → opaque surfaces; `prefers-reduced-transparency` → opaque; `prefers-contrast: more` → stronger separators/text.

## Color
Neutrals from Apple's palette (`--gray-*`), semantic text `--text-primary/secondary/tertiary` (tertiary ≥ 4.5:1 on cards — never use `--text-quaternary` for readable text).
Accent: `--accent` (icons, rings, tints) · `--accent-fill` (filled controls with white text, ≥ 4.5:1) · `--accent-text` (links/text) · `--accent-tint` (selected/soft backgrounds).
States: `--green/--orange/--red/--purple` + `*-text` (on tints, ≥ 4.5:1) + `*-tint`. Status always pairs color with an **icon + label**.
Charts: `--series-1..4` (validated CVD‑safe order, lightness‑banded, per theme), `--chart-grid`, `--chart-axis`, `--chart-label`, `--chart-missing`. "Not reported" is drawn distinctly — never as zero.

## Typography
`-apple-system`/SF on Apple platforms; Inter (Latin) + IBM Plex Sans Arabic elsewhere.
Scale tokens (`font: var(--type-…)`): display 40 · large‑title 32 · title1 26 · title2 21 · title3 18 · headline 15/600 · body 15 · callout 14 · subheadline 13.5 · footnote 12.5 · caption 11.5 · numeral 36.
Negative tracking only for Latin (`:lang(en)`); **never track Arabic**. Use weight sparingly: 400 body, 500 labels, 600 titles, 700 large titles only.

## Spacing & radius
Spacing `--space-1…20` (4‑pt grid: 4 8 12 16 20 24 32 40 48 64 80). Prefer generous whitespace.
Radius: `--radius-xs 8` chips · `sm 10` icon buttons · `md 12` inputs/buttons · `lg 16` rows/tiles · `xl 20` cards · `2xl 24` panels · `3xl 28` major surfaces · `modal 32` · `pill`.

## Motion
`--dur-fast 150` hover/press · `--dur-normal 220` menus/segments · `--dur-slow 300` panels/pages · springs via `--ease-spring` (CSS `linear()` where supported). Reduced motion disables animation globally.
Micro‑interactions: buttons lift 0.5px on hover and scale .97 on press; cards (`.card.interactive`) lift 2px; icon buttons scale .92 on press; menus pop from their anchor; modals spring in; sheets slide up on mobile.

## Components (class hooks)
- Buttons: `.btn` (secondary) · `.btn.primary` · `.btn.tertiary` (tinted) · `.btn.ghost` · `.btn.danger` (destructive) · `.btn.destructive-soft` · sizes `.sm` `.lg` `.block` · states `:disabled`, `.is-loading`. Icon button: `.icon-btn` (+ `aria-pressed`).
- Fields: `.field` on input/select/textarea, `.lbl`, `.helper`, `.error-text`, `aria-invalid="true"`; `.search-field`; checkboxes/radios are styled natively; toggle: `input.switch`.
- Segmented control: `.tabs` (or `segmented()` in JS) with `button.on`.
- Chips: `.chip` + `.good .warn .crit .info .purple .vault .demo .outline`, `.tiny`.
- Card: `.card` (+ `.interactive`, `.selected`, `.flash`, `.flat`), `.card-head`/`.card-title`, `.card-tools` (reveal on hover/focus; always on touch), `.card-foot`.
- Lists: `.list` (`li.clickable`, `.title`, `.meta`), `.list.separated`, `.list.inset`.
- Tables: `dataTable()` → `.table-wrap > table.tbl.stack-mobile` (sortable headers with `aria-sort`, rows stack into cards ≤640px using `data-label`).
- Popover/menu: `menu(anchor, items)` → `.popover.glass-4 > .menu-item` (keyboard: ↑ ↓ Esc).
- Modal: `modal(title, body, actions)` → centered dialog on desktop, **bottom sheet** on mobile; focus trap, Esc, restores focus.
- Feedback: `toast(msg, {kind, action})`, `skeleton('card'|'list'|'stat'|'chart')`, `emptyState({icon,title,body,actions})`, `errorState(err, retry)`.

## States to design for every component
default · hover · pressed · focused (`--focus-ring`) · selected · disabled · loading · success · warning · error · empty.

## Page layout pattern
```
.page-head  (eyebrow · large title · sub · actions)
content: .grid of .card  |  grouped .list  |  dataTable()
```
Primary information dominates (large numerals, title3 headings); secondary info uses footnote/tertiary. Don't wrap every element in a card.

## Accessibility
WCAG AA contrast for text, visible focus rings, keyboard access for every control, `aria-*` on menus/dialogs/tabs, 44px touch targets on coarse pointers, reduced motion/transparency respected, RTL mirroring for directional icons (`.flip-rtl`).
