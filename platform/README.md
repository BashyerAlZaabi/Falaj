# منصة العمل الذكية — Smart Work Platform

منصة عمل تجمع **داشبورد تفاعلي (Unified Portal + ADAA I)**، و**محادثة ومساعد صوتي (Ask AI)**، و**تطبيقات مؤسسية (My Apps)**، و**مساحة لإنشاء المستندات**، و**مكتب وكلاء (Agents Office)**، مع **Vault** معزول يضم FS ومرصاد.
يعمل فعلياً: يحفظ البيانات، وينفّذ طلباتك من المحادثة عبر أدوات محددة (MCP) مع التحقق من الصلاحيات في الخادم.

> ملاحظة: الرسم المرجعي المشار إليه لم يكن مرفقاً في المستودع؛ بُني الهيكل وفق النص المكتوب للمتطلبات.

---

## التشغيل السريع

```bash
cd platform
npm install
npm run dev          # يشغّل Portal على :4000 و Vault على :4100 (عمليتان منفصلتان)
npm run wajib:sim    # (اختياري) محاكاة «واجب» تدفع بيانات تجريبية إلى FS ومرصاد داخل Vault
```

افتح <http://localhost:4000>. الحسابات التجريبية (كلمة المرور `Demo@2026`):

| المستخدم | الدور | الإدارة |
|---|---|---|
| `president` | الرئيس | مكتب الرئيس (نطاق المؤسسة خارج Vault) |
| `mariam` | مديرة + مدير المنصة | التحول الرقمي |
| `omar` | مدير | العمليات |
| `ahmed`, `sara` | موظف | التحول الرقمي |
| `noura` | موظفة | المالية (ترى FS) |

كل البيانات التجريبية معلَّمة `is_demo` وتظهر في الواجهة بشارة **«تجريبي»**. لإنشاء قاعدة بلا بيانات تجريبية: `SEED_DEMO=0 ADMIN_USERNAME=admin ADMIN_PASSWORD=…` (يُنشأ مدير منصة واحد، ثم تضيف المستخدمين والإدارات من «إدارة المنصة ← المستخدمون» أو عبر API). لإعادة التهيئة: `npm run seed`.

المتطلبات: Node.js ≥ 22.13 (يستخدم `node:sqlite` المدمج — بلا قواعد خارجية). لتصدير PDF: Chromium (`CHROMIUM_PATH`) أو LibreOffice.

## الهيكل

```
                    ┌──────────── Identity (دخول موحّد، أدوار، هيكل تنظيمي، Ed25519 SSO) ────────────┐
                    │                                                                               │ (هوية فقط ↓)
 ┌──────────────────┴───────────────── خارج Vault ─────────────────┐        ┌──────────── Vault (عملية/أصل/قاعدة منفصلة) ─────────┐
 │ Unified Portal ─ ADAA I ─ Ask AI ─ Agents ─ Skills ─ My Apps     │        │  FS            مرصاد                                  │
 │ Agents Office (وكلاء بموافقتك)   Smart Uploader ───────────────────► ingest (كتابة فقط) ► مرصاد                             │
 │        │                                                         │        │  ذكاء داخلي فقط (تلخيص محلي/نموذج داخلي)             │
 │   AI Services (مزودون + توجيه قدرات + سجل استخدام)                │        │  حارس اتصال خارجي: يمنع أي اتصال غير مسموح            │
 │   MCP (أدوات تنفيذ بصلاحيات المستخدم) — لا أدوات لـ Vault         │        └──────────────▲────────────────▲────────────────────┘
 │   portal.db (SQLite)                                              │                       │ واجب → FS      │ واجب → مرصاد (كتابة فقط)
 └───────────────────────────────────────────────────────────────────┘
```

| المكوّن | التنفيذ |
|---|---|
| **Identity** | `server/identity.js` — كلمات مرور scrypt، جلسات HttpOnly، رموز شخصية لعملاء MCP، توقيع SSO (Ed25519) لـ Vault |
| **Unified Portal** | `web/` — شريط تنقل، مساحة رئيسية، لوحة محادثة قابلة للتوسيع، لوحة تحرير ومعاينة جانبية؛ تبويبات على الهاتف |
| **ADAA I** | `#/adaa` — مؤشرات بمصدرها ووقت تحديثها، فتح المؤشر ← نقاشه مع المساعد ← تفاصيله ← إجراء مسموح |
| **Ask AI** | `server/ai/assistant.js` — نص وصوت، سياق المحادثة والواجهة، حالات: جارٍ الفهم/التنفيذ/تم/تعذّر |
| **Agents** | 5 مساعدين (أعمال، داشبورد، مستندات، متابعة، مكتب) لكلٍ أدواته وأدواره — قابلة للإدارة من «إدارة المنصة» |
| **Skills** | ملخص يومي، تقرير المتأخرات، تلخيص، خطة، محضر، خطاب، تحليل ملف — مدخلات/مخرجات/طريقة استدعاء معرّفة |
| **My Apps** | حسب الدور والإدارة؛ الظهور لا يمنح صلاحية البيانات؛ تطبيقات Vault تفتح على أصل Vault |
| **AI Services** | `server/ai/services.js` — عدد غير محدد من المزودين (Anthropic، أي OpenAI-compatible، محلي)، توجيه كل قدرة، اختبار اتصال، سجل استخدام |
| **MCP** | `POST /mcp` (JSON-RPC 2.0) + نفس الأدوات داخلياً للمساعد |
| **Agents Office** | `server/services/office.js` — وكلاء تبنيهم أنت يجهّزون أعمالك المتكررة بجدول، ولا يُنفَّذ شيء إلا بعد مراجعتك وموافقتك |
| **Vault** | `vault/` — FS ومرصاد، قاعدة وسجلات منفصلة، واجهة على أصله فقط |

### مسار تنفيذ أي طلب
1. فهم الطلب وتحديد العنصر (من النص + سياق الواجهة «هذا المشروع/المستند المفتوح» + سياق المحادثة).
2. اختيار المهارة/الأداة ← 3. التحقق من الوكيل والدور ومخطط المدخلات والصلاحيات **في الخادم**.
4. التنفيذ عبر الأداة ← 5. التحقق من الحفظ وتسجيل الإجراء مع بيانات التراجع ← 6. تحديث المحادثة والداشبورد/المستند لحظياً (SSE).

- **لا تُشغَّل شيفرة يولّدها النموذج**؛ النموذج يختار أدوات معرّفة فقط.
- **منع التكرار**: كل طلب يحمل `requestId`؛ إعادة الإرسال أو انقطاع الاتصال تُرجع النتيجة المحفوظة دون إعادة التنفيذ.
- **التراجع** للتعديلات البسيطة، و**تأكيد صريح** قبل الحذف النهائي والمشاركة وتغيير الصلاحيات، وقبل تنفيذ قيمة مؤثرة سُمعت صوتياً.
- لا يُعرض «تم» إلا بعد نجاح الأداة فعلياً؛ الفشل الجزئي يوضّح ما نُفّذ وما لم يُنفّذ.

### حدود Vault
| المصدر | الوجهة | الاتجاه | التنفيذ |
|---|---|---|---|
| واجب | FS | إلى الداخل فقط | `POST /ingest/wajib/fs` برمز خاص، يرجع إيصالاً فقط |
| واجب | مرصاد | إلى الداخل فقط | `POST /ingest/wajib/marsad` |
| Smart Uploader | مرصاد | إلى الداخل فقط | البوابة تمرّر الملف ولا تحفظ منه شيئاً سوى إيصال |

- لا يوجد أي مسار قراءة من Portal أو ADAA I أو AI Services أو MCP إلى Vault؛ بيانات Vault ومخرجات ذكائه في قاعدة Vault فقط.
- لا رؤوس CORS، و`Cross-Origin-Resource-Policy: same-origin`، و`frame-ancestors 'none'`؛ رموز الخدمة للكتابة فقط.
- **حارس الاتصال الخارجي** (`vault/egress-guard.js`) على مستوى `net.Socket#connect`: يمنع أي اتصال إلى خارج قائمة داخلية (مثل خوادم النماذج العامة).
- الدخول إلى Vault بتأكيد هوية موقّع قصير العمر (يُرفض إعادة استخدامه). صلاحيات مدير المنصة لا تعطي أي وصول إلى Vault.

## ربط التكاملات

| التكامل | الحالة في هذه البيئة | ما يلزم |
|---|---|---|
| نموذج لغوي (Anthropic) | **غير متصل** — لا يوجد مفتاح. المساعد يعمل بالفهم المحلي ويوضّح ذلك | `ANTHROPIC_API_KEY` ثم «إدارة المنصة ← AI Services ← اختبار» |
| بوابة نماذج مؤسسية (OpenAI-compatible) | غير متصلة | `LLM_GATEWAY_URL` و`LLM_GATEWAY_KEY`، أو أضف مزوّداً من الواجهة |
| الصوت | Web Speech API في المتصفح (Chrome/Edge/Safari) | لبيئات لا تسمح بخدمات الكلام السحابية: وجّه `stt` لمزوّد خادمي (OpenAI-compatible `/audio/transcriptions`) |
| واجب | **محاكاة** (`npm run wajib:sim`) | عنوان Vault ورموز `WAJIB_*` لدى نظام واجب |
| الخدمة الذاتية للموارد البشرية | **غير متصل** (يظهر كذلك في My Apps) | بيانات اتصال النظام |
| PDF | Chromium ✓ | أو LibreOffice كبديل |
| نموذج داخل Vault | تلخيص استخلاصي محلي ✓ | `VAULT_AI_URL` لخادم نموذج داخلي |

## الأنظمة المؤسسية (داخل المنصة)
| النظام | من يستخدمه | أهم الضوابط |
|---|---|---|
| الأداء الاستراتيجي | إدارة المشاريع الاستراتيجية (لطيفة، حمد) تدير الخطة والمؤشرات؛ ملاك المؤشرات يرصدون القيم | الجميع يطّلع على الخطة؛ الاعتماد لغير من رصد القيمة |
| أهدافي | كل موظف: أهداف يومية/أسبوعية/شهرية/ربعية/سنوية مرتبطة بالأهداف الاستراتيجية | خاصة بصاحبها؛ المدير المباشر يرى ما يُتاح له فقط |
| نظام الأداء | الموظف ومديره والموارد البشرية | تقييم المدير مخفي حتى الإرسال؛ الرئيس يرى المجاميع فقط |
| الاجتماعات | المنظّم والمدعوون | الاجتماعات السرية للمدعوين فقط ولا يصلها المساعد |
| الإفصاح والهدايا | كل موظف + ضابط الامتثال (يوسف) | لا يطّلع إلا صاحب الإفصاح والضابط، وكل اطلاع مسجَّل؛ المدير يرى تعليمات التنحي فقط |
| التدقيق الداخلي | المدققون (عائشة، سعيد)، الإدارات الخاضعة للتدقيق، لجنة التدقيق، والمدقق الخارجي (راشد) | أوراق العمل للمدققين فقط؛ المدقق الخارجي يرى طلباته والردود المعتمدة فقط |
| منصة مقدمي الخدمات | المشتريات (ريم) + بوابة لكل مورد (الأفق، الواحة) | لا يرى أي مورد بيانات مورد آخر أو أي بيانات داخلية |
| المشتريات الذكية | أي موظف (طلب شراء) → المدير → المالية → المشتريات → اللجنة → القانونية | العروض مختومة حتى الفتح بمفتاحين؛ التحليل الذكي بأسماء مقنّعة؛ تنحّي أصحاب التضارب تلقائياً |
| إدارة الأفكار | الجميع + لجنة الأفكار | تقييمات اللجنة سرية حتى القرار |
| الجوائز | الجميع + لجنة الجوائز والموارد البشرية | الترشيحات والدرجات سرية حتى الإعلان |
| الاستبيانات | الجميع + معدّو الاستبيانات | الإجابات بلا هوية؛ النتائج مجمّعة بحد أدنى 5 مشاركين |
| مركز التكامل والتحكم | كل مستخدم + مدير المنصة | إظهار الأنظمة، وصول المساعد لكل نوع بيانات، ربط التقويم (ICS)، منح الصلاحيات بتأكيد وسجل |

**تصنيف البيانات وسياسة المساعد:** لكل نوع بيانات تصنيف (داخلي/سري/سري للغاية) وسياسة للمساعد الذكي و MCP (مسموح/بموافقتك/مغلق). الأنواع المغلقة (الإفصاحات، أوراق التدقيق، العروض، الإجابات الفردية، تقييمات الجوائز، الاجتماعات السرية) لا يمكن فتحها لأي أحد.

**الحسابات الخارجية** (المدقق الخارجي ومقدمو الخدمات) محصورة في بواباتها: لا مساحة عمل ولا مساعد ولا MCP ولا Vault.

## ما يدخله مستخدم ينعكس عند الآخرين
إدارة المشاريع الاستراتيجية تنشئ مشاريع استراتيجية في أي إدارة، وتكلّف موظفين من إدارات مختلفة بمهام، وتقترح تخصيص نسبة من وقتهم (يعتمدها مدير الموظف أو يعدّلها)، وتضع الميزانية والمعالم. يظهر ذلك فوراً في بطاقات «كُلّفت به» و«المحفظة الاستراتيجية» و«سعة الفريق» مع تنبيه، وتتحدّث نسبة الإنجاز لحظياً عند إنجاز المهام.

## المساعد مثل ChatGPT
أيقونة المساعد في كل الصفحات تفتح محادثة كاملة الشاشة (سجل، اقتراحات حسب دورك، إجابات تظهر تدريجياً)، ووضع محادثة صوتية تتفاعل فيه الكرة مع صوتك مع تأكيد القيم الحساسة. الصفحة الرئيسية تبدأ بسؤال «كيف أساعدك اليوم؟».

## التحقق

```bash
npm test        # 237 اختبار API (المنصة + Vault + الأنظمة المؤسسية + المحفظة الاستراتيجية) عبر عمليات حقيقية وقواعد مؤقتة
npm run e2e     # رحلة متصفح Chromium كاملة (22 خطوة) + لقطات في tests/e2e/output
node tests/e2e/screens.mjs <dir> --shot=name@user:#/sys/<key>   # لقطات أي شاشة لأي شخصية
```

- `tests/platform.test.js` — الدخول، CSRF، النطاقات حسب الدور، منع الكتابة غير المصرّح، المشاريع/المهام، الطلب المركّب، السؤال عند نقص معلومة، «هذا المشروع» + الحدث اللحظي، منع التكرار، تخصيص الداشبورد وحفظه واستعادته، المستندات والإصدارات والاستعادة وDOCX/PDF، التأكيد قبل الحذف، التراجع، تأكيد القيمة الصوتية، عزل المستخدمين، MCP، تحليل CSV، البقاء بعد إعادة التشغيل.
- `tests/vault.test.js` — المسارات للداخل فقط، عدم وجود محتوى Vault في ملفات قاعدة البوابة، غياب مسار القراءة، CORS، SSO وإعادة الاستخدام، نطاقات Vault، الذكاء داخله، حارس الاتصال (fetch/https/tls/net).
- `tests/office.test.js` — بناء وكيل بالمحادثة، التحضير دون تنفيذ، الموافقة البشرية فقط (الرموز مرفوضة)، التعديل قبل الموافقة، عدم التنفيذ المزدوج، التخطي والرفض، نطاق المالك، المجدول.
- `tests/sys/*.test.js` — لكل نظام: سير العمل الكامل ومحاولات الوصول غير المصرّح (إدارات أخرى، مدير المنصة، الحسابات الخارجية، الوصول بالمعرّف، تجاوز الحالات، الفصل بين المهام، سياسة المساعد).
- `tests/portfolio.test.js` — التكليف عبر الإدارات، موافقة المدير الصحيح على التخصيص، انعكاس ذلك عند الموظف والمدير، وتحديث الإنجاز في المحفظة.
- `tests/model.test.js` — مسار النموذج المتصل عبر خادم وهمي (OpenAI-compatible وAnthropic Messages): استدعاء الأدوات، فحص الصلاحيات، المفتاح لا يصل للمتصفح، والرجوع الصادق عند الفشل.
