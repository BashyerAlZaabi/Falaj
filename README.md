# 🌳 أكاديمية سفراء الزراعة — Youth Agriculture Ambassadors Academy

منصّة تعليمية عربية غامرة تُعلّم الزراعة عبر **رحلة بصرية سينمائية** وورش عملية
تفاعلية. ليست موقعاً تقليدياً — بل قصّة واحدة متّصلة تمشي فيها عبر الزراعة
الإماراتية: من التراث والنخيل، إلى المهارات والإنتاج، وصولاً إلى الاقتصاد والأمن
الغذائي والمستقبل.

An immersive **Arabic-first, RTL** educational platform for the Youth Agriculture
Ambassadors — cinematic scroll storytelling driven by illustration, plus two
fully interactive workshops. Built to grow from **2 workshops today to hundreds**
without any redesign.

## ✨ ما الذي يميّزها

- **رحلة سينمائية** — كل فصل شاشة كاملة، مع بارالاكس متعدّد الطبقات، وتكبير بطيء
  (Ken Burns)، وذرّات غبار متطايرة، وضوء متحرّك، وانتقالات تلاشٍ ناعمة تتحكّم بها
  بالتمرير — دون منزلقات أو كاروسيل.
- **البطل** — «من الغصن للربح مع سفراء الزراعة» مع زر **ابدأ الرحلة**.
- **مسار تعليمي من ٩ محطّات** — التراث ← الأشجار ← المعرفة ← المهارات ← الإنتاج ←
  الاقتصاد ← الأمن الغذائي ← الابتكار ← المستقبل.
- **ورشتان تفاعليتان بالكامل:**
  - **ركّب الغصن… وكثّر الثمر** (تطعيم وتقليم) — درس بخطوات، مع أنشطة: *اختر
    الغصن*، *طابِق الأدوات*، *رتّب الخطوات*، *تعلّم بالنقر (hotspots)*، واختبار.
  - **ازرع واحسب** (حساب الربح) — **حاسبة ربح حيّة** تحسب التكاليف والإيرادات وصافي
    الربح وربح كل نبتة وهامش الربح ونقطة التعادل والعائد على الاستثمار، مع عدّادات
    متحرّكة ورسوم بيانية وتحدّي مقارنة المحاصيل.
- **مكتبة ورش قابلة للتوسّع** — قسم «ورش سفراء الزراعة» يعرض المتاح اليوم مع
  عناصر «قريباً»، و**تصنيفات مستقبلية** جاهزة (الزراعة المنزلية، الري، التربة،
  البذور، الآفات، الزراعة الذكية، التكنولوجيا الزراعية، الأمن الغذائي، الاستدامة،
  ريادة الأعمال الزراعية).
- **جاهزة للمحتوى (CMS-ready)** — كل ورشة كائن بيانات؛ إضافة ورشة = إضافة عنصر في
  `academy/js/workshops.js` دون أي تغيير في بنية الموقع.
- **الأداء وإمكانية الوصول** — تحميل كسول، صور متجاوبة، تسريع عتادي، دعم كامل
  لـ `prefers-reduced-motion`، وتصميم متجاوب للجوال واللوحي والحاسوب.

## 🚀 التشغيل

موقع ويب صرف بلا خطوة بناء أو تبعيات. افتح `index.html` مباشرة، أو شغّل خادماً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🗂️ البنية

```
index.html                 ← الهيكل: البطل، المسار، مكتبة الورش، شاشة الورشة
academy/
  css/academy.css          ← نظام التصميم (هوية زراعية إماراتية دافئة، RTL)
  js/icons.js              ← أيقونات SVG مضمّنة
  js/scenes.js             ← مشاهد SVG متعدّدة الطبقات للفصول السينمائية
  js/workshops.js          ← طبقة المحتوى: الورش، التصنيفات، الفصول (CMS)
  js/academy.js            ← محرّك التمرير، العرض، الأنشطة، الحاسبة، التوجيه
  assets/                  ← الرسوم التوضيحية (البطل، الفريق) والشعار
```

## ➕ إضافة ورشة جديدة

أضف كائناً إلى مصفوفة `workshops` في `academy/js/workshops.js`:

```js
{
  id: "irrigation", status: "live", category: "الري",
  title: "…", subtitle: "…", cover: "scene:smart", icon: "droplet",
  duration: "٢٠ دقيقة", level: "مبتدئ", description: "…",
  objectives: [ … ],
  lesson:   [ { title, body }, … ],
  activities: [ /* choice | match | order | hotspot | calculator | compare */ ],
  quiz:     [ { q, options, answer }, … ],
  tips:     [ { who, text }, … ],
  related:  [ "graft" ]
}
```

ستظهر الورشة تلقائياً في المكتبة وتُبنى رحلتها التفاعلية بالكامل — دون لمس أي كود.
