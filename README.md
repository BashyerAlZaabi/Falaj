# 🌴 فلج رياضة — Falaj Fitness

تطبيق رياضي تفاعلي فيه **شخصية إماراتية** (رجل بالكندورة والغترة، أو أنثى بالعباية والشيلة) تمثّلك،
مع **ليدر بورد عالمي**، ونظام **نقاط وعملات**، و**متجر ملابس وإكسسوارات** للشخصية،
وخاصية **مشاهدة فيديو لكسب عملات** عند نقص المال.

## ✨ المزايا

- **شخصية إماراتية قابلة للتخصيص** — مرسومة بالكامل بصيغة SVG وتتغيّر فوراً حسب الملابس المرتداة.
- **تمارين رياضية** — 8 تمارين، كل تمرين يعطيك نقاط ⭐ وعملات 🪙 مع مؤقّت تفاعلي.
- **التصنيف العالمي 🏆** — تنافس مع 25 لاعباً من حول العالم، وترتفع في الترتيب كلما جمعت نقاط.
- **نظام المستويات** — كل 250 نقطة = مستوى جديد، مع شريط تقدّم.
- **المتجر 🛍️** — أزياء، غطاء رأس (غترة/شماغ/كاب)، نظارات، إكسسوارات (ساعة، ميدالية، سماعات)، وأحذية.
- **مشاهدة فيديو 🎬** — إذا ما عندك عملات كافية، شاهد فيديو واكسب 50 عملة.
- **سلسلة الأيام 🔥** — تتبّع للأيام المتتالية.
- **حفظ تلقائي** — كل التقدّم يُحفظ في المتصفح (localStorage).

## 🚀 التشغيل

التطبيق ويب صرف بدون أي تبعيات أو خطوات بناء. افتح `index.html` مباشرة في المتصفح،
أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## 🗂️ البنية

```
index.html        ← الهيكل والشاشات
css/styles.css    ← التصميم (RTL، داكن، هوية إماراتية)
js/data.js        ← التمارين، عناصر المتجر، لاعبو التصنيف
js/avatar.js      ← مولّد الشخصية الإماراتية (SVG)
js/app.js         ← منطق التطبيق (الحالة، الحفظ، التفاعل)
```

## 🎮 طريقة اللعب

1. اكتب اسمك واختر شخصيتك (رجل / أنثى).
2. ادخل تبويب **التمارين** ونفّذ تمارين لتجمع نقاط وعملات.
3. ارتفع في **التصنيف العالمي** كلما زادت نقاطك.
4. في **المتجر**، اشترِ ملابس وإكسسوارات وغيّر مظهر شخصيتك.
5. نفدت العملات؟ اضغط **شاهد فيديو واكسب** 🎬.
