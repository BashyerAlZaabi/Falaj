# 🌴 فلج رياضة — Falaj Fitness

تطبيق رياضي تفاعلي فيه **شخصية إماراتية** (رجل بالكندورة والغترة، أو أنثى بالعباية والشيلة) تمثّلك،
مع **ليدر بورد عالمي**، ونظام **نقاط وعملات**، و**متجر ملابس وإكسسوارات** للشخصية،
وخاصية **مشاهدة فيديو لكسب عملات** عند نقص المال.

## ✨ المزايا

- **شخصية إماراتية قابلة للتخصيص** — مرسومة بالكامل بصيغة SVG/3D وتتغيّر فوراً حسب الملابس المرتداة.
- **تمارين رياضية** — 8 تمارين مع **فئات** (كارديو، قوة، رشاقة…) و**مستويات صعوبة**، كل تمرين يعطيك نقاط ⭐ وعملات 🪙 مع مؤقّت تفاعلي.
- **هدف اليوم 🎯** — حلقة تقدّم يومية لإكمال 3 تمارين.
- **الإنجازات 🏅** — 15 إنجازاً تُفتح تلقائياً مع تنبيهات عند الإنجاز.
- **التصنيف العالمي 🏆** — منصّة تتويج لأفضل 3 + تنافس مع 25 لاعباً من حول العالم.
- **نظام المستويات** — كل 250 نقطة = مستوى جديد، مع احتفال (قصاصات + صوت) عند الترقية.
- **المتجر 🛍️** — أزياء، غطاء رأس، نظارات، إكسسوارات، وأحذية.
- **مشاهدة فيديو 🎬** — اكسب 50 عملة عند نقص الرصيد.
- **صفحة حسابي 👤** — الإحصائيات، الإنجازات، تعديل الاسم، تبديل الشخصية، التحكّم بالصوت، وإعادة الضبط.
- **مؤثرات صوتية واهتزاز** — تُولَّد عبر WebAudio (بلا ملفّات) وقابلة للإيقاف.
- **تصميم متجاوب وسهل الوصول** — شريط جانبي على الشاشات الكبيرة، دعم لوحة المفاتيح، واحترام «تقليل الحركة».
- **حفظ تلقائي** — كل التقدّم يُحفظ في المتصفح (localStorage).

## 🚀 التشغيل

التطبيق ويب صرف بدون أي تبعيات أو خطوات بناء. افتح `index.html` مباشرة في المتصفح،
أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## 🗂️ البنية

```
index.html        ← الهيكل والشاشات (مع ARIA)
css/styles.css    ← نظام التصميم (RTL، داكن، متجاوب، هوية إماراتية)
js/icons.js       ← مكتبة أيقونات SVG + الشعار
js/data.js        ← التمارين، المتجر، الإنجازات، لاعبو التصنيف
js/state.js       ← متجر الحالة (التخزين، الاشتقاق، التعديلات)
js/fx.js          ← المؤثرات (صوت WebAudio، اهتزاز، قصاصات)
js/avatar.js      ← مولّد الشخصية الإماراتية (SVG)
js/avatar3d.js    ← الشخصية ثلاثية الأبعاد (Three.js)
js/app.js         ← العرض والتفاعل
```

## 🎮 طريقة اللعب

1. اكتب اسمك واختر شخصيتك (رجل / أنثى).
2. ادخل تبويب **التمارين** ونفّذ تمارين لتجمع نقاط وعملات.
3. ارتفع في **التصنيف العالمي** كلما زادت نقاطك.
4. في **المتجر**، اشترِ ملابس وإكسسوارات وغيّر مظهر شخصيتك.
5. نفدت العملات؟ اضغط **شاهد فيديو واكسب** 🎬.
