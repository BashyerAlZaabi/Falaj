# 🤝 سفراء فلج — مدير مشروع السفراء

تطبيق ويب صرف (بلا تبعيات ولا خطوات بناء) لإدارة **برنامج سفراء فلج**:
متابعة السفراء، وإسناد المهام، وتنظيم الفعاليات، وتحفيز الفريق بنظام نقاط ولوحة شرف.

## ✨ الشاشات

- **اللوحة** — مؤشرات فورية (عدد السفراء، المهام المفتوحة والمكتملة، الفعاليات القادمة، إجمالي النقاط)،
  وشريط تقدّم المهام، وقائمة المهام التي تقترب مواعيدها، وسجل أحدث النشاطات.
- **السفراء** — بطاقات لكل سفير (المنطقة، الحالة، النقاط، المهام) مع إضافة وتعديل وحذف ومنح نقاط.
- **المهام** — لوحة كانبان بثلاثة أعمدة (جديدة / قيد التنفيذ / مكتملة) مع الأولوية والموعد النهائي
  والسفير المسؤول. إنجاز المهمة يمنح السفير **25 نقطة** تلقائيًا.
- **الفعاليات** — فعاليات قادمة ومنتهية مع المكان والسفراء المشاركين.
- **لوحة الشرف 🏆** — ترتيب السفراء حسب النقاط مع أشرطة نسبية وميداليات.

## 🚀 التشغيل

افتح `ambassadors/index.html` مباشرة، أو شغّل خادمًا محليًا من جذر المستودع:

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000/ambassadors/
```

## 💾 الحفظ

كل الحالة تُحفظ في المتصفح عبر `localStorage` (المفتاح `falaj_ambassadors_v1`).
زر **↺ إعادة تعيين** في الترويسة يعيد البيانات التجريبية الأولية.

## 🗂️ البنية

```
ambassadors/
  index.html      ← الهيكل والشاشات والنافذة المنبثقة
  css/styles.css  ← الثيم الداكن النيوني بهوية فلج (RTL)
  js/app.js       ← الحالة، الحفظ، التصيير، النماذج، الكانبان
```
